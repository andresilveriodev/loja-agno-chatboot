# Guia de estilo de resposta – Fase 3

**Objetivo:** Respostas curtas e escaneáveis no WhatsApp: 1–3 linhas + opções; bullets; detalhes só sob demanda.

**Atualizado em:** 2026-02-25

---

## 1. Padrão geral

- **Comprimento:** Resposta padrão em **1 a 3 linhas** (+ opções quando fizer sentido).
- **Uma ideia por linha** quando houver mais de um dado.
- Evitar blocos longos; se o conteúdo for extenso, usar **“ver mais”** (ver seção 3).

---

## 2. Uso de bullets e emojis

- **Bullets curtas** para listar informações no mesmo bloco:
  - ✅ Preço | ⏱️ Prazo | 📍 Entrega
  - Ou por linha: `⏱️ Atendimento: Seg a Sex, 8h às 18h`
- **Emojis:** 1 a 3 por mensagem, com moderação (tom profissional).
- **Negrito no WhatsApp:** `*texto*` para destacar uma palavra ou frase (ex.: *Digite 0 para atendente.*).

**Exemplos:**

```
⏱️ Prazo varia por região. Informe seu CEP que confirmamos.
📍 Endereço: Rua X, 123. Atualizado em 2026-02.
✅ Garantia conforme fabricante. Troca dentro do prazo legal.
```

---

## 3. “Ver mais” sob demanda

- **Quando oferecer:** Sempre que a resposta “completa” for longa (mais de 3 linhas ou texto denso) e existir versão resumida.
- **Frase padrão:** *“Se quiser, digite *ver mais* para os detalhes.”*
- **Gatilhos do usuário:** “ver mais”, “detalhes”, “completo”, “quero mais”, “mais informações” → enviar a versão expandida.
- **Regra:** Detalhes longos **só** quando o usuário pedir.

---

## 4. Opções e números

- Menu e escolhas: **1), 2), 3)** ou **1) … 2) …** em linhas separadas.
- Sempre que houver handoff: lembrar *Digite 0 para atendente.*

---

## 5. Resumo para implementação

| Item            | Regra                                                |
|-----------------|------------------------------------------------------|
| Linhas          | Padrão 1–3 linhas por mensagem                      |
| Múltiplos dados | Bullets (✅ ⏱️ 📍 etc.) ou uma linha por dado       |
| Conteúdo longo  | Resumo primeiro + oferta “ver mais”                 |
| Ver mais        | Detectar “ver mais”/“detalhes” e enviar texto completo |
| Opções          | Numeradas (1, 2, 3); 0 = atendente                   |

---

- [x] Uso consistente de bullets (⏱️ 📍 ✅) para múltiplas informações.
- [x] Detalhes longos só quando o usuário pedir (“ver mais” / “detalhes” / “completo”).
